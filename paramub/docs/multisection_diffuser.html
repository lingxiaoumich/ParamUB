Floor & Diffuser — Multisection

Multisection Bezier Diffuser

Drop-in replacement for the legacy angle + radius diffuser. Each cross-section is a cubic Bezier in the XZ plane, lofted across Y for a smooth laterally-varying diffuser. The implementation is layered on two reusable primitives so the Bezier construction can be used standalone.

Overview

Set FloorSpec.diffuser_sections (or UnderbodySpec.diffuser_sections) to a list of DiffuserSection instances. Each section defines the diffuser's profile in the XZ plane at one Y position. The builder auto-mirrors sections at y_mm > 0 across Y=0 and lofts through all sections. When set, the legacy diffuser_angle_deg / diffuser_radius_mm are ignored.

The same machinery exists for the front splitter: FloorSpec.splitter_sections / UnderbodySpec.splitter_sections takes a list of SplitterSection instances. It is the symmetric construction at the front of the car — same Bezier parameterisation, with front_x_mm / front_z_mm / front_angle_deg instead of rear_*, and the start tangent along +X (toward the front) instead of −X. Either, both, or neither list can be set.

Independent N and Y. Splitter and diffuser are built as independent lofts and sewn to the flat-floor face at their (auto-extracted) kickline edges. The two lists can have different numbers of sections and different y_mm values. The only required match is the outermost y_mm: both lists' largest Y must equal floor_width/2 so each loft reaches the floor's lateral edge.
Tangency. Every diffuser Bezier starts horizontal in −X (toward the rear); every splitter Bezier starts horizontal in +X (toward the front). The flat floor is horizontal everywhere. So both lofts meet the flat floor with C1 continuity at the kicklines by construction — you don't tune anything for it.

Three-layer API

The Bezier construction lives in three layers, each one building on the previous. You can call any layer directly.

LayerFunction / classInputsUse when…
1 cubic_bezier_edge(p0, p1, p2, p3) Four cq.Vector control points. You already have the four control points and just need a cq.Edge.
2 cubic_bezier_from_tangents(p0, p3, t0, t3, s0, s3) Two endpoints, two outgoing tangent direction vectors (3D — need not be unit length), two relative strengths. You want to specify the curve by its endpoints + tangent directions and tune the handle strength as a fraction of the chord length |P3 − P0|. Direction-of-travel convention: both t0 and t3 point along curve travel (outgoing at the start, outgoing at the end).
3 DiffuserSection Y, kick X, rear X & Z, rear angle, two strengths. You want the underbody diffuser case where P0 is on the flat floor and the start tangent is along the X axis. The DiffuserSection dataclass encodes these constraints and delegates to Layer 2. 
from paramub import cubic_bezier_edge, cubic_bezier_from_tangents
import cadquery as cq

# Layer 1 — explicit 4-point Bezier (general purpose):
edge = cubic_bezier_edge(
    cq.Vector(0, 0, 0),
    cq.Vector(100, 0, 0),
    cq.Vector(150, 0, 80),
    cq.Vector(200, 0, 100),
)

# Layer 2 — endpoints + tangent directions + relative strengths:
edge = cubic_bezier_from_tangents(
    p0 = cq.Vector(0, 0, 0),
    p3 = cq.Vector(200, 0, 100),
    t0 = cq.Vector(1, 0, 0),         # leaves P0 along +X
    t3 = cq.Vector(0, 0, 1),         # arrives at P3 going +Z
    start_strength = 0.4,            # |P0-P1| = 0.4 * |P3-P0|
    end_strength   = 0.4,            # |P3-P2| = 0.4 * |P3-P0|
)
Why relative strengths? Normalising by the chord |P3 − P0| makes shapes scale consistently — doubling the curve span keeps the same visual character. The same numeric strength value gives the same "roundness" whether the chord is 50 mm or 500 mm.

How one section is constructed

A cubic Bezier has four control points: P0, P1, P2, P3. P0 and P3 are the endpoints (on the kickline and on the rear edge); P1 and P2 are tangent handles that shape the curve in between. You don't set the control points directly — you set seven parameters that build them. The diagram below shows one section at y_mm = 0 with the parameter→geometry mapping called out in blue.

Red: the cubic Bezier curve from P0 (kickline) to P3 (rear endpoint). Dashed gray: tangent handles P0→P1 and P3→P2 — the curve "leaves" P0 in the direction of P1 and "arrives" at P3 from the direction of P2. Blue labels show the seven user-set parameters that build the four control points.

Why the curve is automatically tangent to the floor

Look at the line P0→P1: it lies on the flat floor (same Z as the floor, just stepping backward in X by start_strength × |P0−P3|). Because a Bezier's start tangent direction equals (P1 − P0), the curve must leave P0 flat. That's why the diffuser meets the floor with no visible crease at the kickline. You don't have to opt in — it falls out of the parameterisation.

Same idea at the rear: P3→P2 defines the exit tangent direction. rear_angle_deg rotates that handle relative to horizontal; end_strength controls how far along that direction P2 sits — bigger strength = the curve commits to the rear-angle direction sooner.

Parameter reference

Each DiffuserSection takes seven arguments. They are all in millimetres / degrees and have no defaults — you must set them explicitly.

Parameter Builds Geometric meaning Direction of effect
y_mm Section's Y Y-position of this cross-section. Must be ≥ 0; auto-mirrored to −y_mm. Lateral placement of the profile across the floor width.
kick_x_mm P0.x X where the diffuser starts curving up. Increase (less negative) → diffuser starts earlier (longer kick). Decrease → flat floor extends further before the kick.
rear_x_mm P3.x X where the diffuser ends. Decrease (more negative) → longer diffuser ramp.
rear_z_mm P3.z Absolute Z height of the diffuser exit (must be ≥ ride_h). Higher value → more aggressive total kick rise.
rear_angle_deg Direction of P3→P2 Tangent angle at the rear exit, measured up from −X (the rearward flow direction). Larger → steeper, more vertical exit. Smaller → curve nearly flat at exit.
start_strength Length of P0→P1 divided by chord |P0−P3| How long the curve stays horizontal-tangent before bending. Dimensionless; typical values 0.2–0.5. Larger → flat dwell past kick line, curve bends late. Smaller → curve starts bending immediately at the kick.
end_strength Length of P3→P2 divided by chord |P0−P3| How strongly the curve commits to the rear-exit direction. Dimensionless; typical values 0.2–0.5. Larger → curve points at the rear angle earlier in its travel. Smaller → exit angle barely realised; ramp looks shallower.
Validation. The constructor rejects rear_x_mm ≥ kick_x_mm (the curve must move rearward), negative rear_z_mm, and negative strengths. The middle control points P1 and P2 may overlap each other in X — that's allowed, and useful for tight S-curves.

Shape cookbook

You want…Adjust
Diffuser to start farther back (later kick) Make kick_x_mm more negative.
Longer / shorter diffuser ramp Make rear_x_mm more / less negative.
Steeper exit (more aggressive kick) Increase rear_angle_deg and/or rear_z_mm.
Gentle, gradual curve Increase both strengths (start_strength, end_strength) so the curve eases through the kick.
Sharp "elbow" — long flat, then quick kick Large start_strength, small end_strength, large rear_angle_deg.
Traditional shallow ramp diffuser Small strengths, small rear_angle_deg, modest rear_z_mm.

Combining multiple sections

You can specify any number of sections at y_mm ≥ 0. The builder mirrors them to y_mm < 0 automatically, sorts by Y, and lofts through all of them:

  • N = 2 sections (after mirror): ruled (straight) loft between the two profiles. Each Y between them is a linear interpolation of the two Bezier shapes.
  • N ≥ 3 sections: smooth spline loft through all profiles. Curvature in Y is gentle and continuous.

Each section is independent — you can vary any of the seven parameters between sections. Common patterns:

EffectWhat varies across sections
V-shaped kickline in plan Only kick_x_mm changes; all other shape parameters identical → diffuser flares earlier outboard.
Centre tunnel (mild centre, aggressive outboard) Lower rear_z_mm / rear_angle_deg at y_mm = 0; higher at outboard sections.
Inverse centre tunnel Opposite — aggressive at centre, mild outboard.

Usage

In examples/makeUB.py, set diffuser_sections on the UnderbodySpec. When set, it overrides the legacy diffuser_angle_deg / diffuser_radius_mm. 

from paramub import (
    DiffuserSection, UnderbodySpec, generate,
    WheelSpec, TireSpec, SpokeSpec,
)

diffuser_sections = [
    DiffuserSection(
        y_mm           = 0.0,         # centreline
        kick_x_mm      = -1350.0,     # diffuser starts at rear axle
        rear_x_mm      = -2150.0,     # ends at rear of underbody
        rear_z_mm      = 200.0,       # exits 100 mm above ride height
        rear_angle_deg = 8.0,         # gentle exit angle
        start_strength = 0.37,        # ~300 mm flat dwell past kick
        end_strength   = 0.37,
    ),
    DiffuserSection(
        y_mm           = 900.0,       # outboard (at the floor edge)
        kick_x_mm      = -1200.0,     # kicks 150 mm earlier than centre
        rear_x_mm      = -2150.0,
        rear_z_mm      = 300.0,       # higher exit than centre
        rear_angle_deg = 12.0,        # steeper exit
        start_strength = 0.21,
        end_strength   = 0.26,
    ),
]

spec = UnderbodySpec(
    # ... (plan, ride, wheels, etc.)
    diffuser_sections = diffuser_sections,
)

generate(spec, output_dir="outputs/UB1", stem="ub",
         output_mode="all", output_parts=True, export_step=True)
