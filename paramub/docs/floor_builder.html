Floor & Diffuser Builder

Overview & dispatch

build_floor(FloorSpec) returns the underbody underside as a zero-thickness CadQuery surface. There are two construction modes, picked automatically from FloorSpec:

WhenModeReturns
both splitter_sections and diffuser_sections are None Legacy: single XZ contour (flat → tangent-filleted arc → ramp) swept across the floor width. One cq.Face (ruled surface).
either splitter_sections or diffuser_sections is set Multisection: independent Bezier lofts for the splitter (front) and diffuser (rear), sewn to a flat middle floor at the extracted kicklines. A sewn Shell of up to three faces (splitter loft + flat floor + diffuser loft).
Solid-mode floor (a thin slab) was removed. CFD / aero meshers extrude wall thickness themselves; the parametric floor is always a zero-thickness Face / Shell.

Legacy: angle + radius diffuser

When neither splitter_sections nor diffuser_sections is set, the floor is built from a single XZ contour at Y = 0:

Underside profile at Y = 0 — flat floor → tangent fillet → inclined diffuser ramp. The fillet's tangent points are computed from diffuser_radius_mm and diffuser_angle_deg so the three segments meet smoothly with no kinks. Note the Z axis is not to scale with X.

The contour is swept across floor_width_mm as a ruled surface — every Y has the same XZ profile. There is no front splitter.

Multisection: Bezier splitter + diffuser

Set FloorSpec.splitter_sections and/or FloorSpec.diffuser_sections to a list of SplitterSection / DiffuserSection instances to lift the diffuser (and add a front splitter) to a properly laterally-varying surface lofted from per-Y Bezier cross-sections.

Plan view

Plan view of the floor — a rectangle of floor_width_mm by (floor_x_max − floor_x_min). The underbody assembler cuts wheelhouse footprints (red rectangles) into this rectangle so each wheel can pass through. The multisection variant uses the same Y-span; the only plan-shape change is that the splitter and diffuser kicklines can be slanted (per-section kick_x_mm) instead of straight across.

below-cropper helper

build_below_cropper(spec) returns a solid half-space below the underbody underside (extending well past the floor edges in X and Y). The wheelhouse builder uses it to crop arch faces so the rear arches follow the diffuser slope instead of hanging out below it.

The legacy version uses the analytic XZ contour. The multisection version extrudes each face of the lofted Shell straight downward by 2 m and fuses them, so the cropper matches the lofted geometry exactly.

Both modes are shared infrastructure — the floor builder and the cropper helper agree on the same contour by construction (legacy uses the same _diff_geometry() helper; multisection extrudes the actual floor faces).

Usage

Legacy (default)

from paramub import FloorSpec, build_floor

spec = FloorSpec(
    floor_x_min=-2150, floor_x_max=2200,
    diffuser_start_x_mm=-1350,
    diffuser_angle_deg=7,
    diffuser_radius_mm=500,
)
face = build_floor(spec)        # cq.Face

Multisection

from paramub import FloorSpec, build_floor, DiffuserSection, SplitterSection

spec = FloorSpec(
    floor_x_min=-2150, floor_x_max=2200,
    floor_width_mm=1800,
    diffuser_sections=[
        DiffuserSection(y_mm=0,   kick_x_mm=-1350, rear_x_mm=-2150,
                        rear_z_mm=200, rear_angle_deg=8,
                        start_strength=0.37, end_strength=0.37),
        DiffuserSection(y_mm=900, kick_x_mm=-1200, rear_x_mm=-2150,
                        rear_z_mm=300, rear_angle_deg=12,
                        start_strength=0.21, end_strength=0.26),
    ],
    splitter_sections=[                 # optional
        SplitterSection(y_mm=0,   kick_x_mm=1450, front_x_mm=2200,
                        front_z_mm=150, front_angle_deg=5,
                        start_strength=0.30, end_strength=0.30),
        SplitterSection(y_mm=900, kick_x_mm=1400, front_x_mm=2200,
                        front_z_mm=180, front_angle_deg=8,
                        start_strength=0.25, end_strength=0.25),
    ],
)
shell = build_floor(spec)        # sewn cq.Shell

Implementation notes

True zero-thickness surface. The floor is always a Face (legacy) or sewn Shell (multisection) — no thickness. STL exports cleanly as a single-sided triangle mesh; CFD meshers extrude wall thickness themselves.
Legacy open-wire contour assembly. The legacy underside contour is built by hand from three cq.Edge.makeLine / makeThreePointArc primitives and joined with cq.Wire.assembleEdges. Building a Workplane chain and pulling edges().vals() only returns the latest edge, not all of them — a real footgun.
Multisection construction. Splitter and diffuser are each built as independent BRepOffsetAPI_ThruSections lofts (ruled for N=2 sections, smooth for N≥3). The flat-floor face is constructed planar at ride_h with boundary edges EXTRACTED from each loft's kickline rail, so all three pieces are sewn watertight via BRepBuilderAPI_Sewing. C1 tangency at the kicklines is automatic — each Bezier starts with horizontal tangent in X, and the flat floor is horizontal everywhere.
Legacy diffuser geometry equations. Given α = diffuser_angle and R = diffuser_radius: the fillet eats R·tan(α/2) off the flat portion along the floor, and that same distance is consumed along the ramp. Increasing R thus pushes the flat-floor end of the fillet forward and the diffuser tangent point rearward.
