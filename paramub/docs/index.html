ParamUB — parametric wheel + underbody generator

Six builders compose into one car-underbody assembly. Builders 1–2 feed builder 3 (wheel); builders 4–5 plus four wheels feed builder 6 (underbody). A separate shell-extraction pre-processor strips wheels and underbody from a reconstructed whole-car mesh; the integrate_underbody.py driver bridges the two — measures the shell's silhouette, builds a matching parametric underbody (multisection Bezier splitter + diffuser), aligns frames, trims to the shell's perimeter, and writes a combined STL.

Unified entry — generate

A single function takes one combined spec and writes either an STL file or a full bundle (STL + 5-view PNGs + composite preview + log + parameter JSON). The user guide has full examples; the short form: 

from paramub import generate, UnderbodySpec

# Just the STL
generate(UnderbodySpec(), output_dir="out", stem="ub", output_mode="stl")

# Full bundle: STL + view PNGs + composite preview + log + spec.json
generate(UnderbodySpec(), output_dir="out", stem="ub", output_mode="all")

# Left half only (y < 0) — symmetric CFD setups
generate(UnderbodySpec(), output_dir="out", stem="ub_half", half_only=True)
The renderer runs in a subprocess (PyVista / OCP llvmpipe conflict). See paramub/_render_views.py.

Integrating with a reconstructed shell

integrate_underbody.py at the repo root ties the generator to a shell extracted by run_shell.py: probes the shell at Y = 0 and Y = 700 for the front and rear lowest-edge anchors, builds matching multisection splitter + diffuser sections pinned to those anchors, generates the underbody at the shell's scale, transforms it into the shell frame (mirroring +X), takes the left half, and trims its perimeter to the shell's lower silhouette (2D concave hull of the open-edge points). Writes the trimmed underbody + a combined shell+UB STL + debug renders. 

python integrate_underbody.py \
    --shell-meta outputs/shell/<name>_meta.json \
    --output-dir outputs/integrate
