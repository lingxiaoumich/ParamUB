ParamUB — parametric wheel + underbody generator

Six builders compose into one car-underbody assembly. Builders 1–2 feed builder 3 (wheel); builders 4–5 plus four wheels feed builder 6 (underbody). A separate shell-extraction pre-processor strips wheels and underbody from a reconstructed whole-car mesh so the upper shell can be merged with this generated underbody.

shell_extract + run_shell.py Take a reconstructed whole-car mesh (UltraShape / Hunyuan3D); canonicalize axes; remove wheels, wheelhouses, and underbody; output a single-component upper shell ready to merge with the generated underbody. shell_extract.html

Unified entry — generate

A single function takes one combined spec and writes either an STL file or a full bundle (STL + 5-view PNGs + composite preview + log + parameter JSON): 

from paramub import generate, UnderbodySpec

# Just the STL
generate(UnderbodySpec(), output_dir="out", stem="ub", output_mode="stl")

# Full bundle: STL + view PNGs + composite preview + log + spec.json
generate(UnderbodySpec(), output_dir="out", stem="ub", output_mode="all")
The renderer runs in a subprocess (PyVista / OCP llvmpipe conflict). See paramub/_render_views.py.
