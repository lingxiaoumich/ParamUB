User guide

ParamUB

Parametric car underbody generator built on CadQuery. One dataclass in, STL + preview out.

Install

conda activate paramub        # provides cadquery, pyvista, trimesh, matplotlib

Quick start

from paramub import generate, UnderbodySpec

generate(
    UnderbodySpec(),              # defaults: 2.7 m wheelbase, 225/45 R18, etc.
    output_dir="outputs/demo",
    stem="ub",
    output_mode="all",            # "stl"  -> just ub.stl
                                  # "all"  -> ub.stl + ub_preview.png + ub.log + ub.json
    output_parts=True,            # also emit FLOOR.STL + WHEEL_FL/FR/RL/RR.STL
    export_step=True,             # also emit ub.step  (+ part STEPs when output_parts)
)

Outputs

FileWhenContents
<stem>.stlalways Merged assembly (floor + wheelhouses + 4 wheels).
<stem>_preview.pngoutput_mode="all" 8-panel composite: iso, top, front elevation, Y=0 section, front+rear axle sections, front+rear tire details, plus parameter footer.
<stem>.logoutput_mode="all" Mirrored stdout/stderr.
<stem>.jsonoutput_mode="all" Full spec tree as JSON.
FLOOR.STL, WHEEL_FL.STL, WHEEL_FR.STL, WHEEL_RL.STL, WHEEL_RR.STL output_parts=True One STL per assembly part. Filenames are fixed UPPERCASE.
<stem>.stepexport_step=True Merged BREP STEP file with named subparts (no tessellation; opens cleanly in any CAD tool).
FLOOR.STEP, WHEEL_FL.STEP, … WHEEL_RR.STEP export_step=True + output_parts=True One STEP per assembly part.

Spec layout

One root spec composes the whole thing. Edit any subspec independently.

UnderbodySpec
├── vehicle plan        wheelbase_mm, front_overhang_mm, rear_overhang_mm,
│                       track_front_mm, track_rear_mm
├── ride / floor        ride_height_mm, floor_width_mm, floor_thickness_mm,
│                       floor_angle_deg
├── diffuser            diffuser_start_x_mm (None = rear axle),
│                       diffuser_angle_deg, diffuser_radius_mm
├── wheelhouses         wheel_house_axial_clearance_mm,
│                       wheel_house_lateral_clearance_mm,
│                       front_steering_clearance_mm,
│                       front_wheel_house_fillet_mm, rear_wheel_house_fillet_mm
├── alignment           camber_front_deg, camber_rear_deg,
│                       toe_front_deg, toe_rear_deg
└── wheel: WheelSpec
    ├── tire:  TireSpec   (section_width, aspect_ratio, rim_diameter_in,
    │                       sidewall_bulge, shoulder_radius, tread_width,
    │                       crown_radius, rim_flange)
    └── spoke: SpokeSpec  (wheel_width, hub_bore, wheel_offset (ET),
                           dish_depth, num_spokes, spoke widths, window gaps,
                           rim_band_width, spoke_thickness, ...)

# Optional: separate rear wheel
UnderbodySpec.rear_wheel = WheelSpec(...)  # None -> reuse front wheel

Common tweaks

from paramub import generate, UnderbodySpec, WheelSpec, TireSpec, SpokeSpec

spec = UnderbodySpec(
    wheelbase_mm=2900,
    ride_height_mm=80,
    diffuser_angle_deg=10,
    front_wheel_house_fillet_mm=150,
    wheel=WheelSpec(
        tire=TireSpec(section_width_mm=265, aspect_ratio=35, rim_diameter_in=20),
        spoke=SpokeSpec(num_spokes=10, wheel_offset_mm=45),
    ),
)
generate(spec, output_dir="outputs/sport", stem="sport", output_mode="all")

Full parameter reference

Per-builder guides with labeled diagrams and complete parameter tables:

  • tire_builder — tire cross-section
  • spoke_builder — disc, spoke windows, rim barrel
  • wheelhouse_builder — arch shape, fillets, trim
  • floor_builder — floor + diffuser geometry

Upper-shell extraction

If you start from a reconstructed whole-car mesh (UltraShape / Hunyuan3D) and want to drop in this generator's parametric underbody, run the seven-step shell-extraction pipeline first to strip wheels, wheelhouses, and underbody: 

conda activate paramub
python run_shell.py --input data/car.stl --output-dir outputs/shell
# writes outputs/shell/car_final.stl  (single-component upper shell)

See the shell_extract guide for the full seven-step walkthrough with per-step renders, the visibility classifier, the cut-zone guard, and all tuning knobs.
